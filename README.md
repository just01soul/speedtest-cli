# SpeedTest

Консольный скрипт для замера скорости скачивания: делает 10 последовательных GET-запросов к указанному URL, дожидается полного ответа на каждый и печатает среднюю скорость.

## Единицы измерения (главное)

| Величина | Единица | Как считается |
|---|---|---|
| **Объём скачанного** | **Mbit** (мегабит) | `bytes × 8 / 1 000 000` |
| **Время запроса** | **ms** (миллисекунды) | `hrtime.bigint()` → нс → мс |
| **Скорость скачивания** | **Mbit/s** (мегабит в секунду) | `Mbit / (ms / 1000)` |

**Почему мегабиты, а не мегабайты:** мегабит в секунду (Mbit/s) — стандартная единица скорости в телекоме, у интернет-провайдеров и в speedtest.net. 1 мегабит = 1 000 000 бит. В одном байте — 8 бит, поэтому объём в мегабитах = `байты × 8 / 10⁶`.

## Требования

- Node.js 14+ (используются только встроенные модули `http`, `https`, `url`)
- `npm install` **не нужен**

## Запуск

```bash
node speedtest.js <url>
```
